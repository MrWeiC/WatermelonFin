WatermelonFin / Regression audit / 2026-10-28–29

从“能登录”到真正能用

基于真实 Jellyfin 服务器与受限账号，验证媒体导航、搜索、电影和剧集播放、音轨、字幕，以及设置与诊断入口。每个截图来自实际运行的应用。

权限边界：账号非管理员，禁止内容删除及文件夹删除。测试启动前会拒绝权限不符合要求的账号；没有执行删除操作，也没有修改权限。密码从 macOS Keychain 读取，仅保留在本地驱动进程中。

修复前后 · 同一 iPhone 13 Pro Max / iOS 26.5

测试发现与修复

  1. 媒体页忽略安全区域，第一排卡片被导航栏覆盖。修复后同时验证坐标不重叠和真实导航。
  2. 手机复用了大图标与系统 bordered 按钮，造成截字和红色胶囊背景。改为 plain 卡片、更强的图片遮罩；辅助功能大字体切换为单列。
  3. 当前服务器拒绝 SDK 的 GET QuickConnect/Initiate。改用 POST，保留反向代理路径，测试夹具同步严格检查 HTTP 方法。
  4. MPV 对 anamorphic H.264 的多余限制触发转码，原有四条音轨只剩默认一条。移除这一限制，真实播放验证英文音轨切换。
  5. 播放菜单会被五秒自动隐藏计时器移除。音轨、字幕与播放选项改为明确的选择面板；打开时暂停自动隐藏，关闭后恢复。
  6. 续播按钮只朗读剩余时间。增加明确的 Play/Resume 辅助功能名称和稳定标识。
  7. iOS 27 的自动搜索栏布局没有呈现输入框。明确指定始终显示导航搜索栏，并重测搜索到播放。
  8. iPad 横屏播放返回后详情标题和播放按钮消失。让详情头部保持挂载，下方季/推荐等内容保留延迟加载，验证旋转、关闭和返回。

证据与范围

播放验证读取同一模拟器的服务器会话，要求播放时间前进、暂停状态变化、拖动后位置有明显改变且与滑块显示值对应、音轨/字幕索引变化。截图另外确认视频帧、横屏和选择面板。脱敏的服务器播放状态证据保留暂停、时间和轨道索引。真实服务器的进度/续播记录会随正常播放更新。

UI/UX Pro Max 检查：导航安全区、可读字号、图片上文字对比、44pt 音轨/字幕触摸目标、大字体布局。独立代码审查检查了导航、兼容性改动、菜单生命周期和受限账号检查；审查不替代运行测试。

没有声称已覆盖：实体 iPhone/iPad/Apple TV、所有编解码器/网络条件、原生 AVPlayer 全套操作。tvOS 此次提供编译与单元回归证据，未声称完成遥控器端到端播放。现有 Live TV 页面仍是 Coming soon 占位页，不能算直播播放通过。账号/服务器详情截图留在本地结果包，不放入公开仓库。
